# 0.4.0 interim measurements

Recorded on 2026-10-04 with branch `feat/0.4.0`, on the same Ryzen 9 5900X / WSL2 / Temurin 25.0.4
setup as [NS-CPU-001-report.md](NS-CPU-001-report.md). **The machine was busy:** a 24-hour model
training run used about 18 of the 24 hardware threads, so average-time JMH results had error bars larger
than the values. The numbers below are **minimum latencies** (`-bm sample`, p0.00, 1 fork,
4 x 1 s warmup, 5 x 1 s measurement). Minimum latency is robust to preemption, but it is not the
median used by the §9.3 gate.

| Benchmark | scalar | vector25 | vector vs scalar | 0.3.0 vector25 median |
|---|---:|---:|---:|---:|
| GEMM 32x384x768-NT | 2,723.8 us | 319.5 us | 8.5x | 422.7 us (1x4 NT block) |
| GEMM 8x256x128-NT | 74.4 us | 13.5 us | 5.5x | 14.4 us |
| GEMM 32x768x384-NN | 2,367.5 us | 261.1 us | 9.1x | 292.3 us |
| rowLogSumExp 32x8192 | 1,198.1 us | 184.1 us | 6.5x | ran scalar code |
| sigmoid 512x384 | 451.1 us | 138.5 us | 3.3x | ran scalar code |
| SiLU 512x384 | 530.4 us | 160.8 us | 3.3x | ran scalar code |

Still to measure on an idle machine: the full GemmBench/KernelBench medians for the release report,
and `ParallelGemmBench` (1/6/12/24 workers, NS-CPU-001 §7.3), which would compete directly with the
